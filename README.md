# 2027 Interactive Developer Portfolio (Next.js Edition)

A modern, interactive developer portfolio built with Next.js (App Router), Tailwind CSS, and Framer Motion. This template is designed to replicate the fluidity of Framer's visual editor entirely within a highly customizable, engineer-friendly codebase.

## 🔗 Live Demo
[View Live on GitHub Pages](https://kotao-boop.github.io/developer-portfolio-nextjs/)

## ⚡ Features
- **Next.js App Router**: Optimized performance and static export compatibility.
- **Framer Motion**: Smooth, physics-based scroll and layout animations.
- **Canvas Particle Engine**: Interactive background particles written natively in React.
- **Terminal Typing Effect**: Asynchronous command-line simulation.
- **Bento Grid Architecture**: A responsive, glassmorphism-inspired grid system ideal for showcasing high-end developer projects.
- **Glitch Aesthetics**: Custom CSS keyframes producing an authentic neon glitch effect.

## 📦 Setup & Installation

```bash
# Clone the repository
git clone https://github.com/kotao-boop/developer-portfolio-nextjs.git
cd developer-portfolio-nextjs

# Install dependencies
npm install

# Run the development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment (GitHub Pages)
This project is configured for static export (`output: 'export'`). To deploy:
1. Run `npm run build` to generate the `out/` directory.
2. Push the contents of the `out/` directory to the `gh-pages` branch.
